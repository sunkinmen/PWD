# 臺北工務 探索世界｜架構與更新說明

## 一、檔案架構

```
pwd3d/
├─ index.html            頁面骨架（一般不用改）
├─ css/style.css         介面樣式；顏色變數集中在檔案最上方 :root
├─ js/
│  ├─ content.js         ★內容檔：文字、數據、服務連結、公告、搜尋關鍵字（日常只改這個）
│  ├─ emblems.js         局本部＋五處徽章（SVG）
│  ├─ world.js           3D 世界：場景、角色、車流、相機、操作
│  ├─ audio.js           環境音景（流水、風、鳥鳴、蟲鳴、孩童嬉戲，依位置變化）＋ NPC 語音
│  ├─ ui.js              介面：標題畫面、世界選擇列、資訊卡、面板、選單、搜尋、無障礙版
│  └─ vendor/three.min.js  3D 引擎（Three.js r158，已內建，不依賴外部 CDN）
└─ assets/
   ├─ sky-taipei.jpg       Nano Banana 2 生成的台北全景背景
   ├─ sky-taipei-title.jpg 小尺寸備用
   └─ voice/voice-lines.csv 全部 NPC 台詞與對應 mp3 檔名（錄音用）
```

純靜態網站，不需要資料庫、不需要建置工具。整個資料夾上傳到任何網頁主機（Cloudflare Pages、GitHub Pages、機關主機）即可。

## 二、日常更新（只改 `js/content.js`）

| 要做的事 | 改哪裡 |
|---|---|
| 新增公告 | 該處 `news` 陣列**最前面**加一行：`{ date: '2026-11-05', tag: '路平專案', title: '標題', url: 'https://...' }`（url 可省略） |
| 改數據 | 該處 `metrics` 的 `value` / `unit` |
| 改服務連結 | 該處 `services` 的 `name` / `url` / `icon`（icon 用 emoji） |
| 改介紹文字 | `subtitle`（簡介）、`tagline`（副標）、`badge`（標籤） |
| 改主題色 | `color`（主色）、`soft`（淡色） |
| 搜尋關鍵字 | `SEARCH_INDEX` |
| NPC 台詞、名字、聲音高低 | 檔案最下方 `NPCS`（greet＝招呼語、lines＝業務介紹） |
| 機關資訊 | 檔案最上方 `SITE` |

存檔 → 上傳覆蓋 → 完成。建議改完用瀏覽器打開確認一次。

## 三、更換背景圖

1. 用 Nano Banana 2（Gemini）生成新圖，建議 **21:9 超寬、下方 1/3 較淡霧化**，例如節慶或季節版本。
2. 存成 `assets/` 裡的 jpg（寬約 2500px、品質 85，檔案約 400KB 內）。
3. 改 `content.js` 的 `SITE.skyImage` 檔名。
4. 圖片讀不到時，網站會自動用程式繪製的備用天空，不會壞掉。

## 四、NPC 與語音

- 六位工作人員（局本部、新工、水利、公園、衛工、大地），加上烏龜工程師、山神爺爺。走近會轉身揮手打招呼，按 E 或點對話框聽下一句。
- **預設語音**：瀏覽器內建「中文（台灣）」語音，不用任何檔案。Windows 的 Edge 有自然語音「曉臻 HsiaoChen」，效果最好；iPhone 用「美佳」；Android 用 Google 國語（臺灣）。
- **改用 ElevenLabs 真人感語音**：
  1. 依 `assets/voice/voice-lines.csv` 逐句生成，存成表上的檔名（例：`nco-1-2.mp3`）。
  2. 全部放進 `assets/voice/`。
  3. `content.js` 的 `SITE.voiceFiles` 改成 `true`。缺檔的句子自動改用內建語音。
- 選單可關閉角色語音；環境音按右上 🔊。

## 五、功能與操作

- **標題畫面**：「開始探索」進第一人稱；「城市總覽」看全景。
- **總覽模式**：上方六個世界圖示（← → 鍵切換，或 1–6 鍵），左下顯示該處介紹、數據、公告；「進入世界」直接走進去。
- **探索模式**：WASD／方向鍵移動、Shift 奔跑、拖曳轉視角、走近入口按 E 查看；手機用左下搖桿＋右側拖曳。右上小地圖。
- **選單 ☰**：四季切換、畫質（自動／高畫質／省電）、純文字無障礙版、操作說明。
- **搜尋 ⌕**：輸入「路燈不亮」「借河濱場地」等，直接帶到對應處。
- 造訪紀錄、季節、畫質設定會記在使用者瀏覽器。

## 六、3D 場景配置（world.js）

| 世界 | 位置 | 動態物件 |
|---|---|---|
| 工務局本部 | 中央 | 臺北市政府（雙十字平面、米色石材、深棕入口金字招牌、紅色電子鐘、屋頂柏樹列）、彩虹步道、東側臺北101、飄動旗幟 |
| 新建工程處 | 左前 | 壓路機來回刨鋪（柏油逐步鋪新）、跨河斜張橋、橋上車流 |
| 水利工程處 | 右前 | 抽水站風扇、疏散門升降、YouBike 騎士（踩踏＋輪子轉動）、渡船 |
| 公園路燈處 | 左後 | 噴泉、搖曳花樹、路燈、溜滑梯 |
| 衛工處 | 右後 | 沉澱池刮泥橋旋轉、烏龜工程師從人孔探頭揮手 |
| 大地工程處 | 後方山區 | 梯田擋土牆、山神爺爺坐雲揮手、監測站閃燈、瀑布 |

**全區**：環狀道路上有公車、計程車、轎車、機車（輪子會轉）；放射步道上有行人散步。

**方位**：-z 為北（大地處山區＝陽明山方向）、+x 為東（101 在市府東側），小地圖上方標 N。

**串連設計**：環狀道路車流繞行五處；局本部放射五條彩色光帶步道通往各處；河流從大地處山上發源 → 流經衛工處 → 水利處 → 新工處斜張橋下。

新增 3D 物件：在 world.js 對應的 `buildXXX()` 函式裡用 `M(幾何, 顏色, {x,y,z, parent})` 加；動畫用 `W.updaters.push((t, dt) => {...})`。

## 七、效能與相容

- 手機自動降低解析度、減少粒子；持續低於 30fps 會自動再降。
- 「省電」模式關閉陰影與描邊，適合舊手機。
- 瀏覽器不支援 WebGL 時自動切換純文字版。
- 本機直接雙擊 index.html 即可開啟（不需架伺服器），此時背景圖改讀 `assets/sky-offline.js` 內嵌備份。
- 更換背景圖後若也要本機雙擊可用，請重新產生該檔（內容為 `window.SKY_DATA='data:image/jpeg;base64,…'`）；放上主機則不需要。

- 數據與公告為示意內容，上線前請各處確認。
- 「烏龜工程師」「山神爺爺」為原創角色。
